# TigerFlow 模块二详细设计：任务流 (Task Flow)

> 版本：v1.0 | 模块：Task Flow | 依据：项目需求.md、功能开发清单.md

## 2.1 核心定位

### 2.1.1 定义

**任务流 (Task Flow)** 是 TigerFlow 的"执行主队列"，核心理念是 **"一次只专注一件事"**。

### 2.1.2 核心原则

| 原则 | 说明 |
|------|------|
| **串行推进** | 任务按计划时间排序，强制专注当前任务 |
| **轻量录入** | 点击即创建，不弹窗，直接在列表首条编辑 |
| **自动同步** | 默认同步生成 Life Flow 记录（可关闭） |
| **智能解析** | 自然语言输入，自动解析 `#标签` 和 `@对象` |

### 2.2.2 交互规则

| 步骤 | 行为 |
|------|------|

## 2.3 快速输入与智能解析

### 2.3.1 自然语言输入示例

| 输入内容 | 解析结果 |
|----------|----------|
| `写周报` | 标题: "写周报" |
| `写周报 #工作` | 标题: "写周报", 标签: #工作 |
| `写周报 #工作 @老板` | 标题: "写周报", 标签: #工作, 对象: @老板 |
| `写周报 #工作 @老板 下午3点` | 标题: "写周报", 标签: #工作, 对象: @老板, 时间: 下午3点 |

### 2.3.2 解析规则

#### 标签解析 (`#`)

- 触发字符: `#`
- 结束字符: 空格、换行、另一个 `#`、另一个 `@`
- 模糊匹配: 输入 `工` → 匹配 `工作`
- 自动创建: 匹配不到时，可选择自动创建或显示建议列表

#### 对象解析 (`@`)

- 触发字符: `@`
- 结束字符: 空格、换行、另一个 `@`、另一个 `#`
- 模糊匹配: 输入 `老` → 匹配 `老板`、`老婆`、`老爸`
- 自动创建: 匹配不到时，可选择自动创建新人物

### 2.3.3 智能解析服务

```swift
/// 智能解析服务
class SmartParser {
    /// 解析文本中的标签和对象
    static func parse(_ text: String) -> ParsedResult {
        // 1. 提取 #标签
        let tags = extractTags(from: text)

        // 2. 提取 @对象
        let entities = extractEntities(from: text)

        // 3. 清理文本，移除 # 和 @ 符号
        let cleanTitle = text
            .replacingOccurrences(of: "#\\w+", with: "", options: .regularExpression)
            .replacingOccurrences(of: "@\\w+", with: "", options: .regularExpression)
            .trimmingCharacters(in: .whitespaces)

        return ParsedResult(
            title: cleanTitle,
            tags: tags,
            entities: entities
        )
    }
}

/// 解析结果
struct ParsedResult {
    let title: String
    let tags: [Tag]
    let entities: [Entity]
}
```

## 2.4 标签与对象系统

### 2.4.1 标签 (Tag) 特性

| 特性 | 说明 |
|------|------|
| **颜色永久存储** | 首次创建时生成颜色，后续使用保持一致 |
| **使用频率** | 按使用次数排序，优先显示常用标签 |
| **模糊搜索** | 输入任意字符匹配标签名 |

#### 颜色生成规则

```swift
extension Tag {
    /// 生成一致的颜色（基于名称的哈希）
    static func generateColor(for name: String) -> String {
        let colors = [
            "#FF6B6B", "#4ECDC4", "#45B7D1", "#96CEB4",
            "#FFEAA7", "#DDA0DD", "#98D8C8", "#F7DC6F",
            "#BB8FCE", "#85C1E9", "#F8B500", "#00CED1"
        ]
        let hash = abs(name.hashValue)
        return colors[hash % colors.count]
    }
}
```

## 2.5 Life Flow 同步

### 2.5.1 同步规则

| 场景 | 行为 |
|------|------|
| 创建任务时 | 默认勾选"同步到日程流"，可关闭 |
| 完成任务时 | 可选择同步到日程流（弹窗确认） |
| 删除任务时 | 可选择同时删除日程流记录 |

### 2.5.3 同步实现

```swift
extension FlowItem {
    /// 同步到日程流
    func syncToScheduleFlow(context: ModelContext) {
        // 1. 获取或创建 Schedule Flow
        let scheduleFlow = getOrCreateFlow(type: .schedule, context: context)

        // 2. 创建 Schedule Item
        let scheduleItem = FlowItem(
            title: self.title,
            content: self.content,
            occurredAt: Date(),
            flow: scheduleFlow,
            domain: self.domain,
            isFromTaskSync: true,
            sourceItemId: self.id
        )

        // 3. 复制标签和对象
        lifeItem.tags = self.tags
        lifeItem.entities = self.entities

        // 4. 保存
        context.insert(lifeItem)
    }
}
```

## 2.6 任务排序与优先级

### 2.6.1 排序规则

| 排序模式 | 说明 |
|----------|------|
| **按计划时间** | 默认，按 `occurredAt` 升序（早到到晚） |
| **按创建时间** | 按 `createdAt` 降序（最新优先） |
| **按优先级** | 高 → 中 → 低 |

### 2.6.2 优先级显示

```
┌───┐

├───┤
│ - │  中优先级 - 无标识
├───┤

└───┘
```

## 2.8 组件详细设计

### 2.8.1 QuickInputField

```swift
/// 快速输入框 - 支持智能解析
struct QuickInputField: View {
    @Binding var text: String
    var onTextChange: (String) -> Void
    var onSubmit: () -> Void

    @State private var showTagSuggestions: Bool = false
    @State private var showEntitySuggestions: Bool = false

    var body: some View {
        VStack(alignment: .leading, spacing: 4) {
            TextField("输入任务，回车保存...", text: $text)
                .textFieldStyle(.plain)
                .font(.body)
                .onSubmit(onSubmit)
                .onChange(of: text) { _, newValue in
                    handleInputChange(newValue)
                }

            // 解析预览
            ParsedPreviewView(text: text)
        }
    }

    private func handleInputChange(_ text: String) {
        // 检测 # 或 @ 触发建议
        if text.hasSuffix("#") {
            showTagSuggestions = true
        } else if text.hasSuffix("@") {
            showEntitySuggestions = true
        } else {
            showTagSuggestions = false
            showEntitySuggestions = false
        }
    }
}
```

### 2.8.2 SuggestionsPopover

```swift
/// 建议弹出面板
struct SuggestionsPopover: View {
    let type: SuggestionType
    let suggestions: [Any]
    let onSelect: (Any) -> Void

    var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            Text(type == .tag ? "标签建议" : "对象建议")
                .font(.caption)
                .foregroundColor(.secondary)
                .padding(.horizontal, 8)
                .padding(.vertical, 4)

            Divider()

            if suggestions.isEmpty {
                Text("无匹配")
                    .font(.caption)
                    .foregroundColor(.secondary)
                    .padding(8)
            } else {
                ForEach(suggestions, id: \.self) { item in
                    Button {
                        onSelect(item)
                    } label: {
                        suggestionRow(item)
                    }
                    .buttonStyle(.plain)
                }
            }

            Divider()

            Button {
                // 创建新标签/对象
            } label: {
                Label("创建新\(type == .tag ? "标签" : "对象")", systemImage: "plus")
                    .font(.caption)
                    .padding(8)
            }
            .buttonStyle(.plain)
        }
        .background(Color(.windowBackgroundColor))
        .cornerRadius(8)
        .shadow(color: .black.opacity(0.15), radius: 4, y: 2)
    }

    @ViewBuilder
    private func suggestionRow(_ item: Any) -> some View {
        if let tag = item as? Tag {
            HStack {
                Circle().fill(Color(hex: tag.color)).frame(width: 8, height: 8)
                Text(tag.name)
                Spacer()
            }
            .padding(.horizontal, 8)
            .padding(.vertical, 6)
        } else if let entity = item as? Entity {
            HStack {
                Text(entity.emoji)
                Text(entity.name)
                Spacer()
            }
            .padding(.horizontal, 8)
            .padding(.vertical, 6)
        }
    }
}
```
