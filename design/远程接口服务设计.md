# TigerFlow 远程接口服务设计

> 数据同步到自建 Spring Boot + MySQL 服务

---

## 1. 架构概述

```
┌─────────────────┐         ┌──────────────────────────┐
│   TigerFlow    │  HTTPS   │    Spring Boot          │
│  (iOS/macOS)  │◄───────►│    leshare-tigerflow    │
└─────────────────┘         └──────────────────────────┘
        │                           │
        ▼                           ▼
┌─────────────────┐         ┌──────────────────────────┐
│   SwiftData    │         │      MySQL               │
│  (本地存储)     │         │   (tigerflow schema)     │
└─────────────────┘         └──────────────────────────┘
```

### 设计目标

- 数据本地存储优先，离线可用
- 定期同步到远程服务器
- 支持增量同步，减少网络请求
- 统一的认证机制

### 模块选择

在现有 `leshare-cloud` 项目中新增 **独立 Module** `leshare-tigerflow`：
- 独立包结构：`shop.leshare.tigerflow.*`
- 独立数据库 schema：`tigerflow`
- 独立 API 前缀：`/tigerflow/v1/...`

## 3. 数据库设计

### 3.1 用户认证表

```sql
-- 用户表 (支持多渠道登录)
CREATE TABLE `tf_user` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    `username` VARCHAR(50) COMMENT '用户名 (用户名密码登录时必填)',
    `password` VARCHAR(255) COMMENT '密码(BCrypt加密, 用户名密码登录时)',
    `nickname` VARCHAR(50) COMMENT '昵称',
    `email` VARCHAR(100) COMMENT '邮箱',
    `avatar_url` VARCHAR(500) COMMENT '头像URL',
    `phone` VARCHAR(20) COMMENT '手机号',
    `status` VARCHAR(20) DEFAULT 'active' COMMENT '状态: active/disabled',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_username (`username`),
    INDEX idx_phone (`phone`),
    INDEX idx_email (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='TigerFlow用户表';

-- 第三方登录关联表
CREATE TABLE `tf_user_auth` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `auth_type` VARCHAR(20) NOT NULL COMMENT '登录类型: password/phone/apple/wechat',
    `auth_id` VARCHAR(100) NOT NULL COMMENT '第三方唯一标识',
    `auth_info` JSON COMMENT '第三方返回的详细信息',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '绑定时间',
    `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    UNIQUE INDEX idx_auth (`auth_type`, `auth_id`),
    INDEX idx_user_id (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='第三方登录关联表';

-- Token 表
CREATE TABLE `tf_auth_token` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    `user_id` BIGINT NOT NULL COMMENT '用户ID',
    `token` VARCHAR(255) NOT NULL UNIQUE COMMENT '访问Token',
    `refresh_token` VARCHAR(255) COMMENT '刷新Token',
    `device_id` VARCHAR(64) COMMENT '设备ID',
    `device_name` VARCHAR(100) COMMENT '设备名称',
    `expires_at` DATETIME NOT NULL COMMENT '过期时间',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    INDEX idx_token (`token`),
    INDEX idx_refresh_token (`refresh_token`),
    INDEX idx_user_id (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='认证Token表';

-- 手机验证码表
CREATE TABLE `tf_sms_code` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `phone` VARCHAR(20) NOT NULL COMMENT '手机号',
    `code` VARCHAR(6) NOT NULL COMMENT '验证码',
    `purpose` VARCHAR(20) NOT NULL COMMENT '用途: login/register/reset',
    `expires_at` DATETIME NOT NULL COMMENT '过期时间',
    `used_at` DATETIME NULL COMMENT '使用时间',
    `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_phone_code (`phone`, `code`, `purpose`),
    INDEX idx_expires_at (`expires_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='手机验证码表';
```

## 4. API 端点设计

### 4.1 认证接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /tigerflow/v1/auth/register | 用户名密码注册 |
| POST | /tigerflow/v1/auth/login | 用户名密码登录 |
| POST | /tigerflow/v1/auth/phone/send | 发送手机验证码 |
| POST | /tigerflow/v1/auth/phone/login | 手机号验证码登录 |
| POST | /tigerflow/v1/auth/apple/login | Apple ID 登录 |
| POST | /tigerflow/v1/auth/wechat/login | 微信登录 |
| POST | /tigerflow/v1/auth/refresh | 刷新 Token |
| POST | /tigerflow/v1/auth/logout | 登出 |

#### 4.1.1 用户名密码注册

```
POST /tigerflow/v1/auth/register
```

**Request:**
```json
{
    "username": "tigerio",
    "password": "123456",
    "nickname": "Tiger",
    "deviceId": "device-uuid-001"
}
```

**Response (成功):**
```json
{
    "code": 0,
    "message": "success",
    "data": {
        "userId": "1234567890",
        "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "expiresAt": "2026-03-12T14:00:00Z"
    }
}
```

#### 4.1.2 用户名密码登录

```
POST /tigerflow/v1/auth/login
```

**Request:**
```json
{
    "username": "tigerio",
    "password": "123456",
    "deviceId": "device-uuid-001",
    "deviceName": "iPhone 17 Pro"

```

#### 4.1.3 手机号验证码登录

```
# 步骤1: 发送验证码
POST /tigerflow/v1/auth/phone/send
```

**Request:**
```json
{
    "phone": "13800138000",
    "purpose": "login"  // login / register / reset
}
```

**Response:**
```json
{
    "code": 0,
    "message": "验证码已发送"
}
```

```
# 步骤2: 验证码登录
POST /tigerflow/v1/auth/phone/login
```

**Request:**
```json
{
    "phone": "13800138000",
    "code": "123456",
    "deviceId": "device-uuid-001",
    "deviceName": "iPhone 17 Pro"
}
```

#### 4.1.4 Apple ID 登录 (Sign in with Apple)

```
POST /tigerflow/v1/auth/apple/login
```

**Request:**
```json
{
    "identityToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": "002000.1a2b3c4d5e6f7g8h9i0...",  // Apple 提供的 user identifier
    "fullName": {
        "givenName": "Tiger",
        "familyName": "Liu"
    },
    "deviceId": "device-uuid-001",
    "deviceName": "iPhone 17 Pro"
}
```

**说明：**
- `identityToken`: Apple 返回的 JWT token，需服务端验证
- `user`: Apple 提供的唯一用户标识符
- 首次登录时可获取用户姓名，后续仅返回 user

#### 4.1.5 微信登录

```
POST /tigerflow/v1/auth/wechat/login
```

**Request:**
```json
{
    "code": "微信授权码",
    "deviceId": "device-uuid-001",
    "deviceName": "iPhone 17 Pro"
}
```

**说明：**
- 需要在微信开放平台配置授权回调
- 服务端使用 code 换取 openid 和 unionid

#### 4.1.6 刷新 Token

```
POST /tigerflow/v1/auth/refresh
```

**Request:**

## 7. 同步策略

### 7.1 同步时机

| 场景 | 触发条件 | 优先级 |
|------|----------|--------|
| 启动同步 | App 启动时 | 高 |
| 手动同步 | 用户点击同步按钮 | 高 |
| 定时同步 | 每 5 分钟（可选） | 低 |
| 退出同步 | App 进入后台 | 中 |
| 网络恢复 | Network reachability 变化 | 高 |

### 7.2 增量同步原理

```
客户端:
  lastSyncTime = "2026-03-12T10:00:00Z"

服务端:
  SELECT * FROM tf_flow_item
  WHERE user_id = ?
  AND updated_at > lastSyncTime
  AND deleted_at IS NULL

  SELECT id FROM tf_flow_item
  WHERE user_id = ?
  AND updated_at > lastSyncTime
  AND deleted_at IS NOT NULL
```

### 7.3 冲突解决策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| server-wins | 服务端数据优先 | 大多数场景 |
| client-wins | 客户端数据优先 | 用户明确操作的 |
| last-write-wins | 最后写入优先 | 时间敏感数据 |
| ask-user | 提示用户选择 | 重要冲突 |

**冲突检测：**
```json
// 推送时检测冲突
{
    "itemId": "uuid-001",
    "localVersion": "2026-03-12T10:00:00Z",
    "serverVersion": "2026-03-12T10:05:00Z",
    "conflict": true
}
```

### 7.4 离线支持

- **本地优先**: 所有操作先写入 SwiftData
- **状态标记**: `syncStatus = pending / synced / conflict`
- **自动重试**: 网络恢复后自动同步 pending 数据
- **队列管理**: 同步失败不影响用户使用

### 9.2 核心代码示例

#### APIClient.swift

```swift
class APIClient {
    static let shared = APIClient()
    private let baseURL = "https://api.leshare.shop/tigerflow/v1"
    private let keychain = KeychainService.shared

    func request<T: Decodable>(
        endpoint: String,
        method: HTTPMethod,
        body: Encodable? = nil
    ) async throws -> T {
        var request = URLRequest(url: URL(string: "\(baseURL)\(endpoint)")!)
        request.httpMethod = method.rawValue
        request.setValue("application/json", forHTTPHeaderField: "Content-Type")

        // 添加 Token
        if let token = keychain.getAccessToken() {
            request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
        }

        if let body = body {
            request.httpBody = try JSONEncoder().encode(body)
        }

        let (data, response) = try await URLSession.shared.data(for: request)

        guard let httpResponse = response as? HTTPURLResponse else {
            throw APIError.invalidResponse
        }

        guard httpResponse.statusCode == 200 else {
            throw APIError.httpError(statusCode: httpResponse.statusCode)
        }

        return try JSONDecoder().decode(T.self, from: data)
    }
}
```
