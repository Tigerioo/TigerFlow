# TigerFlow 后端对接模块设计

> 版本：v1.0 | 日期：2026-03-13

---

## 1. 设计目标

实现 iOS/macOS 客户端与自建后端服务的数据同步，替代 CloudKit。

### 核心原则

- **本地优先 (Local-First)**：所有操作先写本地 SwiftData，再异步同步到服务端
- **增量同步**：基于 `updatedAt` 字段做增量拉取，减少网络开销
- **离线可用**：无网络时正常操作，联网后自动同步
- **冲突处理**：本地数据优先，按时间戳合并

## 2. 架构设计

### 2.1 模块结构

```
tigerflow/
├── Services/
│   ├── APIClient.swift        # 网络请求封装
│   ├── AuthService.swift      # 认证服务
│   └── SyncService.swift     # 同步服务
├── Models/
│   └── API/                  # API 请求/响应模型
├── Storage/
│   └── UserDefaults          # Token 存储
└── Views/
    └── Auth/                 # 登录/注册界面
```

### 2.2 数据流

```
用户操作 → SwiftData(本地) → [变更队列] → APIClient → 后端 API
                ↑                                    ↓
                └────────── 同步响应 ←───────────────┘
```

    // Access Token (短期, 1小时)

### 4.2 认证流程

```
1. 用户输入用户名密码
2. POST /api/v1/auth/login
3. 存储 Access Token 和 Refresh Token
4. 后续请求 Header 携带: Authorization: Bearer <token>
5. Token 过期时，使用 Refresh Token 刷新
```

## 5. 同步模块设计

### 5.1 同步策略

| 触发时机 | 策略 | 说明 |
|----------|------|------|
| App 启动 | 增量同步 | 拉取上次同步后的变更 |
| 登录成功 | 全量同步 | 首次获取所有数据 |
| 进入前台 | 增量同步 | 检查新数据 |
| 手动触发 | 增量同步 | 用户下拉刷新 |
| 数据变更 | 延迟同步 | 批量推送到服务端 |

### 5.2 增量同步流程

```
1. 读取本地最后同步时间 (lastSyncTime)
2. POST /api/v1/sync { lastSyncTime: "2026-03-13T10:00:00" }
3. 解析响应:
   - 新增/更新的记录 → 合并到 SwiftData
   - deletedXXX 数组 → 软删除本地记录
4. 更新 lastSyncTime
```

### 5.3 同步响应结构

```swift
struct SyncResponse: Codable {
    let syncTime: Date
    let flows: [FlowDTO]?
    let flowItems: [FlowItemDTO]?
    let domains: [DomainDTO]?
    let tags: [TagDTO]?
    let entities: [EntityDTO]?

    // 删除的记录ID
    let deletedFlows: [Int64]?
    let deletedFlowItems: [Int64]?
    let deletedDomains: [Int64]?
    let deletedTags: [Int64]?
    let deletedEntities: [Int64]?
}
```

### 5.4 冲突处理

采用 **"本地优先"** 策略：

1. 本地操作 → 立即更新 SwiftData
2. 异步推送到服务端
3. 服务端返回冲突时（极少情况），保留本地数据
4. 定期增量同步确保最终一致

## 6. 数据模型映射

### 6.1 SwiftData → API

| SwiftData | API | 说明 |
|------------|-----|------|
| Flow | FlowDTO | 流程 |
| FlowItem | FlowItemDTO | 流程项 |
| Domain | DomainDTO | 领域 |
| Tag | TagDTO | 标签 |
| Entity | EntityDTO | @对象 |

### 6.2 ID 处理

- SwiftData 使用 UUID (`id: UUID`)
- API 使用 Long (`id: Int64`)
- 转换：`apiId = uuid.hashValue` 或使用 String 类型

## 7. 错误处理

### 7.1 网络错误

| 错误 | 处理 |
|------|------|
| 无网络 | 记录到待同步队列 |
| 超时 | 重试 3 次 |
| 服务器错误 | 提示用户，稍后重试 |

### 7.2 业务错误

| 错误码 | 含义 | 处理 |
|--------|------|------|
| 401 | Token 过期 | 自动刷新 |
| 403 | 无权限 | 提示重新登录 |
| 404 | 资源不存在 | 清理本地脏数据 |
| 409 | 冲突 | 保留本地 |
