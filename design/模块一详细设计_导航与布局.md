# TigerFlow 模块一详细设计：导航与布局

> 版本：v1.0 | 模块：Navigation & Layout | 依据：项目需求.md

---

## 1.1 基础框架

### 1.1.1 NavigationSplitView 架构

采用 SwiftUI `NavigationSplitView` 实现.sidebar + .detail 双栏/三栏布局。

#### 平台适配策略

| 平台 | 布局模式 | 说明 |
|------|----------|------|
| **macOS** | 三栏布局 | Sidebar + Content + Detail |
| **iPad (横屏)** | 三栏布局 | Sidebar + Content + Detail |
| **iPad (竖屏)** | 两栏布局 | Sidebar (可折叠) + Content |
| **iPhone** | 两栏 + NavigationStack | Tab + 侧滑菜单 |

#### 布局代码结构

```swift
// 主入口布局
NavigationSplitView(columnVisibility: .constant(.all)) {
    SidebarView()
} content: {
    TimelineListView()
} detail: {
    ItemDetailView()
}
```

#### 响应式断点

- **大屏** (≥1024pt): 三栏全显
- **中屏** (768pt-1023pt): 两栏，Detail按需显示
- **小屏** (<768pt): 单栏 + 侧滑

## 1.2 左侧边栏 (Sidebar)

### 1.2.1 Sidebar 结构

Sidebar 采用 `List` + `Section` 实现，分为四大分区：

```
Sidebar
├── Flows (固定)
│   ├── 任务流 (Task Flow)
│   ├── 日程流 (Schedule Flow)
│   ├── 事件流 (Event Flow)
│   └── 自定义 Flow (SubFlows)
│
├── Domains (支持自定义)
│   ├── 工作
│   ├── 家庭
│   ├── 健康
│   ├── 成长
│   └── + 新建领域
│
├── People (自动聚合)
│   ├── 大女儿 (12)
│   ├── 二女儿 (5)
│   ├── 老爸 (3)
│   ├── 老婆 (8)
│   └── + 新建人物
│
└── Tags (自动聚合)
    ├── #电影
    ├── #阅读
    ├── #历史
    └── + 新建标签
```

### 1.2.2 Sidebar 组件设计

#### 分区标题

- 使用 `Section` 的 header 显示分区名
- 分区标题固定大写：`FLOWS`, `DOMAINS`, `PEOPLE`, `TAGS`

#### 行项目 (Row)

| 类型 | 显示内容 | 交互 |
|------|----------|------|
| **Flow** | 图标 + 名称 | 单击选中，右侧显示对应Timeline |
| **Domain** | 图标 + 名称 + 记录数 | 单击筛选 |
| **People** | 头像emoji + 名称 + 记录数 | 单击筛选 |
| **Tag** | #名称 + 记录数 | 单击筛选 |

#### 记录数聚合规则

- Domain/People/Tag 的记录数 = 关联的 FlowItem 总数
- 实时计算，Data Model 层提供 `@Query` 聚合

### 1.2.3 Sidebar 交互

| 交互 | 行为 |
|------|------|
| 单击 Flow | 切换到对应 Flow 的 Timeline |
| 单击 Domain/People/Tag | 进入筛选模式，显示对应 Timeline |
| 长按 Flow/Domain/People | 弹出上下文菜单（编辑、删除） |
| 拖拽排序 | 支持 Flows 和 Domains 自定义顺序 |
| 展开/折叠 | 点击分区标题展开/收起 |

## 1.3 右侧内容区 (Content Flow)

### 1.3.1 Timeline 统一展示规则

**核心原则**：所有 Flow (Task/Life/Event/Custom) 使用完全相同的 Timeline 展示样式。

#### 视觉布局

```
┌─────────────────────────────────────────────────┐
│  [搜索图标]  [Flow名称]              [+新建]    │
├─────────────────────────────────────────────────┤
│                                                 │
│  2026年3月                                      │
│  ┌───┐                                          │
│  │ 6 │ 任务标题 #标签 @对象                      │
│  └───┘                                          │
│       任务标题 #标签 @对象                       │
│                                                 │
│  2026年3月5日                                   │
│  ┌───┐                                          │
│  │ 5 │ 任务标题 #标签 @对象                      │
│  └───┘                                          │
│       任务标题 #标签                            │
│                                                 │
└─────────────────────────────────────────────────┘
```

#### DateCircle (圆形日期)

- **位置**：Item 左侧
- **显示规则**：仅每天最新的一条 Item 显示圆形日期
- **样式**：
  - 圆形背景：系统 accentColor 或自定义颜色
  - 文字：白色，日期数字，居中
  - 尺寸：32x32pt

#### 同一天合并规则

- 同一天的 Item 在视觉上合并，中间无分割线
- 只需要每天第一条显示 DateCircle
- 日期标题（如"2026年3月6日"）作为分组头

### 1.3.2 Timeline 分组结构

Timeline 按 **年 → 月 → 日** 三级分组：

```
Timeline
├── 2026年
│   ├── 3月 (Sticky)
│   │   ├── 6日
│   │   │   └── Item 1
│   │   └── 5日
│   │       ├── Item 2
│   │       └── Item 3
│   └── 2月
│       └── ...
└── 2025年
    └── ...
```

#### StickyHeader 行为

- 滑动到某月时，该月标题"吸"在顶部
- 继续向上滑动时，被更早的月份顶替
- 向下滚动时，StickyHeader 消失

### 1.3.3 Checkbox 显示规则

| Flow 类型 | Checkbox | 说明 |
|-----------|----------|------|
| Task Flow | ✅ 显示 | 左侧圆形/方形Checkbox |
| Life Flow | ❌ 不显示 | 无完成概念 |
| Event Flow | ❌ 不显示 | 无完成概念 |
| Custom Flow | ❌ 不显示 | 聚合视图 |

### 1.3.4 Timeline 数据加载策略

- **分页加载**：初始加载 50 条，上滑加载更多
- **时间范围**：默认加载当年，可扩展加载历史
- **排序**：
  - Task/Life/Event: 按 occurredAt 倒序
  - 自定义 SubFlow: 按 addedAt 倒序

## 1.5 组件详细设计

### 1.5.1 SidebarView

```swift
struct SidebarView: View {
    @Query(sort: \Flow.sortOrder) var flows: [Flow]
    @Query(sort: \Domain.sortOrder) var domains: [Domain]

    var body: some View {
        List(selection: $selectedItem) {
            // Flows Section
            Section("FLOWS") {
                ForEach(flows) { flow in
                    FlowRow(flow: flow)
                        .tag(flow.id)
                }
            }

            // Domains Section
            Section("DOMAINS") {
                ForEach(domains) { domain in
                    DomainRow(domain: domain)
                }
            }

            // People Section
            Section("PEOPLE") {
                // 按记录数排序
            }

            // Tags Section
            Section("TAGS") {
                // 按使用频率排序
            }
        }
        .listStyle(.sidebar)
    }
}
```

### 1.5.2 TimelineListView

```swift
struct TimelineListView: View {
    let flowType: FlowType
    @State private var items: [FlowItem] = []
    @State private var isCreating: Bool = false

    var body: some View {
        ZStack(alignment: .top) {
            // Timeline Content
            TimelineView(items: items)

            // Inline Create (when activated)
            if isCreating {
                InlineEditorView(onSave: saveItem, onCancel: cancelCreate)
            }
        }
        .navigationTitle(flowType.displayName)
        .toolbar {
            ToolbarItem(placement: .primaryAction) {
                Button(action: activateCreate) {
                    Image(systemName: "plus")
                }
            }
        }
    }
}
```

### 1.5.3 TimelineView (核心组件)

```swift
struct TimelineView: View {
    let items: [FlowItem]
    @State private var stickyMonth: String?

    var body: some View {
        ScrollView {
            LazyVStack(alignment: .leading, spacing: 0) {
                ForEach(groupedByMonth, id: \.month) { monthGroup in
                    // Month Header
                    Text(monthGroup.month)
                        .font(.headline)
                        .frame(maxWidth: .infinity, alignment: .leading)
                        .sticky()
                        .padding(.horizontal)
                        .background(Color.systemBackground)

                    // Day Groups
                    ForEach(monthGroup.dayGroups, id: \.day) { dayGroup in
                        ForEach(Array(dayGroup.items.enumerated()), id: \.element.id) { index, item in
                            TimelineItemView(
                                item: item,
                                showDateCircle: index == 0  // 仅每天首条显示
                            )
                        }
                    }
                }
            }
        }
    }

    private var groupedByMonth: [MonthGroup] {
        // 按年/月/日分组逻辑
    }
}
```

### 1.5.4 TimelineItemView

```swift
struct TimelineItemView: View {
    let item: FlowItem
    let showDateCircle: Bool
    let showCheckbox: Bool

    var body: some View {
        HStack(alignment: .top, spacing: 12) {
            // DateCircle or Checkbox
            if showDateCircle {
                if showCheckbox {
                    CheckboxView(isChecked: item.isCompleted)
                } else {
                    DateCircleView(date: item.occurredAt)
                }
            } else {
                // 占位，保持对齐
                Color.clear.frame(width: 32, height: 32)
            }

            // Content
            VStack(alignment: .leading, spacing: 4) {
                Text(item.title)
                    .font(.body)

                if let content = item.content {
                    Text(content)
                        .font(.caption)
                        .foregroundColor(.secondary)
                }

                // Tags & Entities
                HStack {
                    ForEach(item.tags) { tag in
                        TagChip(tag: tag)
                    }
                    ForEach(item.entities) { entity in
                        EntityChip(entity: entity)
                    }
                }
            }

            Spacer()
        }
        .padding(.horizontal)
        .padding(.vertical, 8)
    }
}
```
