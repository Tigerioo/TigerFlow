# TigerFlow 功能开发清单

> 版本：v2.0 | 依据：项目需求.md | 生成日期：2026-03-06

---

## 📦 模块一：导航与布局 (Navigation & Layout)

### 1.1 基础框架
- [ ] **NavigationSplitView 框架**
  - iPad/macOS 三栏布局 (Sidebar + Content + Detail)
  - iPhone 侧滑菜单适配
- [ ] **左侧边栏 Sidebar**
  - Flows 分区：任务流、日程流、事件流、自定义Flow
  - Domains 分区：工作、家庭、健康、成长等（支持自定义）
  - People 分区：人物列表（自动聚合记录数）
  - Tags 分区：标签列表

### 1.2 导航交互
- [ ] **Sidebar 折叠/展开** - 响应式布局适配
- [ ] **导航状态保持** - 切换视图时保留滚动位置
- [ ] **深链接支持** - 从外部链接直接跳转
- [ ] **统一Flow样式** - 所有Flow (Task/Life/Event/Custom) 使用相同的Timeline展示

### 1.3 Timeline 统一展示规则
- [ ] **垂直时间线布局** - 所有Flow采用相同样式
- [ ] **DateCircle 圆形日期** - 仅每天最新的一条Item左侧显示圆形数字
- [ ] **同一天合并** - 无需每个Item都显示日期，仅首条显示
- [ ] **时间倒序** - Item按时间倒序排列
- [ ] **Checkbox 仅Task** - 任务流左侧显示Checkbox，其他Flow不显示
- [ ] **年/月/日分组** - Timeline清晰展示年月日层级
- [ ] **StickyHeader** - 滑动到某月时，月标题固定在顶部

### 1.4 搜索
- [ ] **全局搜索视图** - 关键词搜索
- [ ] **筛选器** - 按标签、对象、领域筛选

---

## 📦 模块二：任务流 (Task Flow)

### 2.1 创建（内联式）+ 排序
- [ ] **内联创建** - 点击创建按钮，不弹窗，直接在列表第一条创建并进入编辑状态
- [ ] **按计划时间排序** - 任务按计划时间排序，强调串行推进
- [ ] **快速输入**
  - 自然语言解析：`写周报 #工作 @老板`
  - 实时解析 `#标签` 和 `@对象`
- [ ] **Life Flow 同步** - 新建任务时默认同步生成Life记录（可关闭）

### 2.2 智能解析
- [ ] **模糊匹配** - 输入"工"过滤"工作"等历史标签
- [ ] **@对象模糊匹配** - @时支持模糊搜索
- [ ] **颜色永久存储** - 标签创建时生成颜色，下次输入保持一致
- [ ] **自动联想** - 输入#或@时显示历史下拉列表

### 2.3 任务操作
- [ ] **转事件** - 一键升级为Event
- [ ] **Checkbox 完成** - 点击Checkbox标记完成

---

## 📦 模块三：日程流 (Schedule Flow)

### 3.1 记录创建
- [ ] **手动记录入口** - 独立的生活记录按钮
- [ ] **内联创建** - 同任务流，点击创建直接在列表首条进入编辑状态
- [ ] **任务同步** - 完成任务时自动同步生成Life记录（可关闭）

### 3.2 展示
- [ ] **日期分组** - 同一天记录合并显示
- [ ] **时间倒序** - 按发生时间倒序
- [ ] **Timeline统一样式** - 使用模块一的展示规则

### 3.3 索引
- [ ] **标签索引** - 通过 `#标签` 建立关系
- [ ] **对象索引** - 通过 `@对象` 建立关系
- [ ] **来源追溯** - 显示关联的任务（如有）

### 3.4 动作
- [ ] **标记纪念** - 标记为"值得纪念"推送到Event Flow

---

## 📦 模块四：自定义 Flow (SubFlow)

### 4.1 管理
- [ ] **创建 SubFlow** - 选择名称、图标、颜色
- [ ] **生命周期** - Pin → 跟踪中 → Unpin（完结保留历史）
- [ ] **SubFlow 列表** - 显示所有Pinned的自定义Flow

### 4.2 聚合
- [ ] **手动添加** - 将Task/Life/Event Item加入SubFlow
- [ ] **智能推荐** - 基于主题推荐相关Item
- [ ] **引用关系** - SubFlow引用而非复制原始Item

### 4.3 展示
- [ ] **独立 Timeline** - 聚合后的时间线
- [ ] **进度可视化** - 跟踪中的SubFlow进度

---

## 📦 模块五：事件流 (Event Flow)

### 5.1 创建
- [ ] **直接创建** - 独立的事件创建入口
- [ ] **内联创建** - 同任务流，点击创建直接在列表首条进入编辑状态
- [ ] **从Task/Life升级** - 一键升级为Event

### 5.2 展示
- [ ] **年/月时间轴** - 按年份月份分组
- [ ] **Timeline统一样式** - 使用模块一的展示规则

### 5.3 字段
- [ ] **标题、时间、背景描述**
- [ ] **相关人物(@)、对象(@)、标签(#)**
- [ ] **来源记录追溯**

---

## 📦 模块六：数据模型 (SwiftData)

### 6.1 实体
- [ ] **FlowType** - task / life / event / custom
- [ ] **Flow** - id, name, type, icon, color, isPinned, sortOrder, createdAt
- [ ] **FlowItem** - id, flowId, title, content, occurredAt, endAt, priority, domainId?, isFromTaskSync, sourceItemId?, createdAt, updatedAt
- [ ] **Domain** - id, name, icon, sortOrder
- [ ] **Tag** - id, name, color (Hex值，永久存储)
- [ ] **Entity (@对象)** - id, name, type, note

### 6.2 关系
- [ ] **Flow 1:N FlowItem**
- [ ] **FlowItem N:N Tag** (FlowItemTag中间表)
- [ ] **FlowItem N:N Entity** (FlowItemEntity中间表)
- [ ] **FlowItem N:1 Domain**
- [ ] **FlowItem 追溯链** (sourceItemId)

### 6.3 智能解析
- [ ] **实时解析** - 输入时解析 #标签 和 @对象
- [ ] **颜色缓存** - 标签创建时自动生成颜色并缓存
- [ ] **自动创建开关** - 可配置是否自动创建新标签/对象
